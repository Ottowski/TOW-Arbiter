# Warhammer: The Old World - Combat Result

## Calculating Combat Result

### Unsaved Wounds Inflicted

Each side's basic combat result equals the number of unsaved wounds it caused this turn from Stand & Shoot charge reactions and during the Combat phase. Removing a model counts as losing the number of wounds it had remaining when removed. Count wounds lost, not casualties.

### Rank Bonus

Units wide enough gain +1 combat result per extra rank behind the first, up to the troop type's maximum. Incomplete rear ranks can count if they have enough models. Disrupted units cannot claim a rank bonus.

### Standards

Standard: If the unit includes a standard bearer, it gains +1 combat result.
Battle Standard: If the unit carries a Battle Standard, it gains an additional +1 (cumulative with a normal standard).

### Flank & Rear Attacks

Flank Attack: Engaged with the enemy's flank arc grants +1 combat result.
Rear Attack: Engaged with the enemy's rear arc grants +2 combat result.
These bonuses are cumulative with other modifiers.

### High Ground

If the fighting rank is higher than the enemy (e.g., along a hill crest), gain +1 combat result.

### Overkill (Combat)

In a challenge, if a character kills the opponent and inflicts more unsaved wounds than the opponent had remaining, gain +1 combat result per excess wound, up to +5.

### Massed Infantry

If one side has higher Unit Strength and contains one or more units with Massed Infantry, that side gains +1 combat result.

### Other Bonuses

Some special rules grant additional combat result points (e.g., Close Order in Combat Order grants +1). Apply such bonuses as described in their respective rules.
